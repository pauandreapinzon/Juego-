# La Travesía del Centauro

Juego de aventura para aprender a dirigir la IA, inspirado en el libro *IA para Creativos* de Paula Pinzón.

Este repositorio contiene la versión ya compilada (sitio estático). Se despliega tal cual en Vercel o GitHub Pages: no necesita comando de build.

Estructura:

- `index.html`
- `assets/` (JS, CSS, `img/` y `audio/`)
